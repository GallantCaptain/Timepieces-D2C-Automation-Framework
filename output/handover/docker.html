2. Profiles are load-bearing

The ISSUE-021 lesson A Compose service with no profile starts with everything. The two Healenium services once had no profile, so docker compose --profile grid up -d tried to pull a Healenium image that no longer resolves — and one failed pull aborts the whole up, so the Grid never started and 15/15 tests failed with SessionNotCreatedException. Every heavyweight, opt-in service now sits behind a profile. Confirm what a command will start before running it:

docker compose --profile grid config --services   # expect: hub + 3 nodes (+ allure, postgres-dev)

3. Bringing services up

docker compose up -d postgres-dev                 # just the metrics DB
docker compose --profile grid up -d               # Grid: hub + chrome/firefox/edge
docker compose --profile security up -d zap       # ZAP daemon (port 8090)
docker compose --profile healenium up -d          # Healenium backend (also needs -Dhealenium.enabled=true)
docker compose --profile grid down                # tear a profile down

4. Containerised test runs (headed video for free)

A container ships with an Xvfb virtual display, so a "headed" browser paints somewhere the Monte recorder can see it — meaning video recording works in Docker even for an unattended run, unlike a headless local run. docker/entrypoint.sh loops over browsers:

for browser in $BROWSERS; do
    mvn test -Dbrowser="$browser" ...     # results accumulate into one Allure report
done
./scripts/run-docker-headed.ps1   # convenience wrapper around the container run

5. Two Postgres instances — not a mistake

  • postgres-dev (postgres:16-alpine) — stores test-run metrics.
  • healenium-postgres (postgres:13) — stores locator-healing data, isolated from metrics.

They are separate on purpose: unrelated data, different lifecycles, and Healenium pins an older Postgres major.

6. ZAP port mapping — the one that bites

Must be 8090:8090 ZAP's single port serves both its REST API and its HTTP proxy, telling them apart by the Host header. A rewriting map like 8090:8080 makes ZAP not recognise itself as the target, treat the API call as proxy traffic, and return a baffling self-inflicted 502. Keep the inside and outside ports identical.

7. Kubernetes

Kubernetes is covered as a generic foundations primer in the team-transition material, but is not implemented in this repo. Docker Compose is the actual container orchestration here. Treat any K8s manifests as illustrative, not deployed.
