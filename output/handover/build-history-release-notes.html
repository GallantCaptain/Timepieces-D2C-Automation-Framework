Late July 2026 — Handover hardening

  • Personal data scrubbed. The departing owner's phone and email removed from every tracked file; secrets (pilot.phone) converted to fail-loud config keys with no defaults. (History still contains them — a filter-repo pass is available if the team wants them gone from history too.)
  • Payment / Security suite reworked. Was failing 6/6 in its Background (asked a homepage for a checkout form). Rewritten to the real flow — sidebar → accessories → Secure Checkout → Razorpay modal → guest contact — 5 green scenarios; card/decline/confirmation left as documented @Manual. Guest contact is filled but never submitted (safety rail against SMSing a real number).
  • Selenium Grid + DEC-0014 delivered. Self-hosted hub + chrome/firefox/edge nodes; parallel cross-browser in one JVM via a thread-local browser pin, verified by per-node session counts.
  • ISSUE-021 fixed. Healenium services had no Compose profile, so the Grid command tried to pull an unresolvable image and aborted — 15/15 false failures. Every heavyweight service now sits behind a profile.
  • Repository layout split. docs/ holds .md source; output/ holds all generated pdf/html (cheatsheet, proposals, these handover guides).
  • Zephyr token scrubbed from history. A leaked API token removed via git filter-repo after a verified backup bundle; all clones invalidated (re-clone, don't pull). Rotation in SmartBear is a team task.

Mid July 2026 — Security, cross-env, RCA

  • OWASP ZAP DAST integrated. Daemon-mode ZAP driven over its REST API; OWASP Top 10 2021→2025 tag-driven classification; production is passive/baseline-only by design, active scans gated to staging with sign-off. Scheduled weekly (Sat staging, Sun prod).
  • Big RCA pass. ~90% of a 71-failure run proved to be framework bugs, not app bugs — cookie-bar interception, hidden responsive twins, tag-qualified testids matching zero nodes, assertions sampling state instead of waiting. Real app defects filed (ISSUE-016…019, incl. a High-severity privacy draft-restore with an on-demand repro probe).
  • ISSUE-020 fixed. BaseRunner was silently overriding -Denv with the suite XML — the framework could test the wrong environment while claiming otherwise. The CLI now wins.
  • Headless by default; guarded video. Video records only where it can capture something real (headed/Docker), skipping headless with a warning.
  • @StagOnly / @ProdOnly environment scopes added.

Early July 2026 — Coverage build-out

  • Page-object model completed across timepieces, accessories, Timepieces World, content and legal pages, with a repo-wide data-testid locator rollout to kill brittle selectors.
  • BDD + TDD suites, parallel execution via ThreadLocal driver + DataProvider, retry analysis, Allure reporting, and the Postgres metrics pipeline.
  • Search-relevance analysis harness (deterministic + exploratory, run N times) surfaced four confirmed search defects (ISSUE-009…012).
  • Team-transition guides authored (CI/CD, Docker/K8s, Healenium, framework design) and the QA infrastructure proposal.

June 2026 — Foundations

  • Framework bootstrapped: Java 25 / Maven / Selenium 4.44 / Cucumber 7 / TestNG 7 / Rest-Assured / Allure.
  • OKF established as authoritative project memory; ADRs 0001–0010 recorded.
  • Config resolution, DriverFactory (ThreadLocal), Hooks, reporting and the dashboard POC stood up.

Known state at handover

  • Local/Docker runs from India are the reliable execution path; hosted CI can show red on Cloudflare grounds (ISSUE-001) — coverage is the mandate, not a green hosted pipeline.
  • Open app-side defects tracked in known-issues.md (privacy draft-restore, checkout redirect, contact-step validation, alt-text, watch-case cart join).
  • The login/OTP scenario is @KnownBroken pending re-mapping after a dev-side rework (ISSUE-023).
