1. Identity & Authentication

1.1 Phone-number OTP login (passwordless)

User flow: land on the login page (Welcome message) → select country (sets dialing code) → enter mobile number → Send OTP → CAPTCHA validation (Cloudflare Turnstile) → OTP verification screen.

Acceptance criteria

  • The Welcome message is clearly visible on load.
  • The region dropdown filters and applies the correct dialing code.
  • Send OTP triggers CAPTCHA validation (unless bypassed in staging).
  • A successful OTP request routes immediately to the OTP entry screen.

3. Automation Framework (as specified)

3.1 Technology stack

Java 25 · Maven · Selenium (web), Appium (mobile), Rest-Assured (API) · Healenium (self-healing) · Cucumber-JVM (BDD) · TestNG (parallel + ThreadLocal driver) · Allure · Log4j2 · Monte screen recorder.

3.2 Design principles

  • BDD — Gherkin scenarios as living documentation.
  • Page Object + Component Object Model — locators abstracted into classes.
  • Fluent interfaces — e.g. loginPage.open().configureCountryCodeByName(...).
  • Separation of concerns — assertions only in step definitions; page objects interact/query.
  • Parallel-ready — thread-safe driver management via DriverFactory + Hooks.
